# Decisions

Decisions about how this repository is run. Decisions about the app's behaviour live in `.specify/memory/constitution.md` and `specs/`.

| # | Decision | Who, when |
|---|---|---|
| 1 | The project is published as a fresh public repository with a single initial commit, and the earlier history stays private. | The owner, 2026-10-14 |
| 2 | `CLAUDE.md` is self-contained. It no longer syncs its rules from the owner's private template repository, and it mentions no tool, skill or process that is not in this repository. | The owner, 2026-10-14 |
| 3 | Development keeps Spec Kit (spec, plan, tasks, implement) and test-first work for every change a user can see. | The owner, 2026-10-14 |
| 4 | The first public release is version 1.0.0, dated 2026-10-14, and versions follow Semantic Versioning from here. | The owner, 2026-10-14 |
| 5 | The repository keeps the name power-backup, and the README says that the app it builds is called Rsync Sync GUI. | The owner, 2026-10-14 |
| 6 | Security problems are reported privately through GitHub's private vulnerability reporting, not in public issues. | The owner, 2026-10-14 |
